# 批量导入与资料文件夹验收记录

日期：2026-11-23。对应 Windows 0.1.4、Android 0.2.5-offline。

## 功能

- 导入窗口可一次选择多个文件，逐份处理并显示进度。失败文件单独显示原因，成功资料保留。
- 资料库和导入窗口均可新建文件夹；进入文件夹后导入，默认保存到当前文件夹。
- 资料可移动到其他文件夹或根目录；支持重命名文件夹，仅允许删除空文件夹。
- 网页和 Windows 支持现有 PDF、Word、PPT 导入；Android 离线版支持 PDF。
- 旧资料默认位于根目录，文件夹随资料库备份保存。
- Android 系统文件选择器显式启用多选，并读取系统返回的多文件列表；取消选择返回空结果。

- 自动测试 55 项全部通过，包含文件夹空名称、过长名称、重复名称、无效目标、非空文件夹删除拦截、导入到文件夹、移动和账号间文件夹隔离。
- 网页正式构建成功。
- 浏览器验证已覆盖网页和离线页面的双 PDF 导入、移动、刷新后保留，以及手机宽度布局。使用隔离测试资料，未写入用户的正式资料库。

- Android APK 构建成功；校验包内 90 个网页资源与本次构建逐个匹配。

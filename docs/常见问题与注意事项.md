# 常见问题与注意事项

对应当前 Windows 0.3.5、Android 0.4.5-offline。下载安装入口见[首页](../README.md#下载与安装)，完整教程见[使用指南](使用指南.md)。

## 下载和安装

**GitHub 的 Code → Download ZIP 能直接安装吗？**

不能。那是源代码，需要开发环境运行。普通用户到 [Releases](https://github.com/kaituozher11-png/yuan-notes/releases/tag/preview-2026-11-28-note-continuation) 下载 `.exe` 或 `.apk`。页面上的 SHA256 校验文件用来核对下载内容；Windows 可用 `Get-FileHash -Algorithm SHA256 文件路径` 计算校验值。

**Windows 要装 Node.js 或 Microsoft Office 吗？**

安装包自带应用运行环境，不需要 Node.js。PDF 处理需要额外安装 Poppler。Word/PPT 转换需要 LibreOffice 等工具，Windows Word 文档可优先使用本机 Word；Microsoft Office 不是所有场景的必需条件。详细路径配置见[Windows 工具配置](使用指南.md#windows-安装与工具配置)。

**安装包为什么提示来源未知？**

Windows 预览包未数字签名，Android 是测试签名。先确认来源是本仓库发布页并核对校验值；这类提示不等于项目已完成系统或商店认证。不要因此全局关闭系统防护。

**Android 提示不能安装或签名冲突怎么办？**

先检查 Android 是否为 8.0+、下载是否完整、设备是否允许本次来源安装，以及已有应用是否来自本项目。不要先卸载含有重要笔记的旧版。先在旧版备份，再反馈完整错误。设备管理策略、其他来源签名或厂商限制需要分别排查。

**有 iPhone/iPad 版、macOS 版或商店链接吗？**

目前没有对应安装包或商店上架版本。“平板版”当前指 Android 平板。浏览器界面支持不同尺寸，但当前也没有官方公共网页版网址。

## 联网和网页使用

**手机必须和电脑连接同一 Wi-Fi 吗？**

当前 Android 离线 APK 不需要。它在设备上保存和处理本地 PDF/笔记。智能生成与助手才需要联网，访问你配置的模型服务；不需要连接电脑服务器。

**本机网页版断网还能用吗？**

本机服务运行且资料、资源可用时，可在同一电脑浏览和手动编辑，AI 功能需联网。网页依赖本机服务；关闭服务、仅打开静态 HTML 或访问其他人的 `127.0.0.1` 都无法获得对应资料。浏览器“安装网页应用”不等于离线 APK，也不会把服务器资料自动复制到手机。

**把 `127.0.0.1:4174` 发给别人能打开吗？**

不能。它表示访问者自己的电脑。要供多人使用，需自行部署服务器、配置域名与 HTTPS，再启用公开账号模式；见[网页版部署说明](网页版部署说明.md)。项目没有替使用者提供免费托管服务器。

**可以上传 `dist/` 到 GitHub Pages 吗？**

普通网页版同时需要文件处理和存储后端，单独静态托管不满足运行条件。Android 离线入口另有原生桥和设备存储环境，也不能把其静态文件直接当作完整公开服务。

## 导入与原文显示

**为什么 Word/PPT 导入失败？**

先确认版本：Android 只直接导入 PDF。电脑端检查 LibreOffice 与 Poppler 是否安装、相关命令是否可找到，安装后是否重启应用。加密、损坏、超大文件或转换超时也可能失败。先在原软件打开，再导出 PDF 测试。

**文件未损坏，为什么仍显示不出来？**

文件有效不代表当前 PDF 引擎支持所有特性。请提供文件类型、大小、应用版本、失败页码和脱敏样例；特别是特殊字体、复杂图像、公式对象或旧文件格式。不要把所有问题都归因于文件损坏。

**Word 的 MathType 公式、编号或字体与原件不一致怎么办？**

Word/PPT 在电脑服务转换后预览，转换工具和字体会影响结果。它不是原生 Office 编辑器。高保真场景优先在 Word/PowerPoint 原软件中导出 PDF，再检查公式、序号、图片和分页，最后导入源笔记。软件不保证自动修复所有原始对象。

**PDF 中有图但预览缺图、页面闪动怎么办？**

先记录平台、版本、缩放、页码、是否最大化及具体操作，用同一 PDF 的其他页比较；更新后仍出现时附可复现样例和截图。不要反复删除正式资料来测试，也不要将“有文字提取结果”当作图片预览已正确。

**为什么选不到文字，或双栏选择不符合预期？**

扫描 PDF 没有文字层，不能直接选字；加密限制或特殊文字编码也可能影响选择。先退出画笔/便利贴放置模式。双栏排版或公式混排仍有异常时，报告左右栏、选择方向、起止位置和页面样例，不要只提供无法定位的“选择失败”。

## 笔记、公式、图片和导图

**图片粘贴没有反应？**

确认复制的是实际图片文件而非地址，或先保存为 PNG/JPEG/GIF/WebP 后使用插入图片。单张最大 5 MB。浏览器和设备剪贴板能力不同，文件选择可作为替代方式。图片编辑支持宽度和对齐，不是自由坐标排版。

**公式显示成普通文本？**

个人笔记请使用“插入公式”与数学编辑器，输入正确 LaTeX 后检查渲染。AI 内容中的公式依赖返回的格式，不能把未经核对的公式文本认作正确排版；模型未给出或原文不清楚的公式不应凭空补全。

**思维导图仍然太小？**

“适应内容”用于全图概览，节点越多整体会越小。查看和编辑细节时选 100% 或放大，开启全屏/专注画布，拖动空白处或滚动；需要空间时加宽/加高，拥挤时自动排版。大图不可能同时保持全部可见和所有字都等大。

**导图可以导入 Xmind 文件、在节点里排数学公式吗？**

当前不支持。支持本软件结构的 JSON，最大 2 MB、500 节点、1500 线。节点暂为文字，结构化公式可放在旁边的笔记区。SVG/PNG 适合展示，JSON 用于保留可编辑结构。

**自动排版是否能消除所有交叉线？**

不能保证。布局会整理节点，保留自由连接；复杂关系和循环仍可能有交叉线。可改为其他布局并手动调整，或分成多张导图。

## 模型连接、生成和助手

**软件是否免费提供模型和额度？**

不提供账号、密钥或额度。模型调用和连接测试可能产生服务商费用；自己部署公开网站还可能有服务器和域名费用。阅读及手动笔记不需要模型。

**已保存连接，为什么还要输入保护口令？**

保护口令用于解密当前设备保存的 API 密钥。至少 8 个字符，不是模型账户密码。忘记后不能靠资料 ZIP 恢复密钥，可重新配置连接；不要把口令或密钥发送到 Issue。

**模型下拉列表没有我的模型？接口自动填错了？**

可以手动填写。预设只提供常见模型与官方兼容地址，转发服务或代理的接口应按该服务商说明输入；同名模型不代表同地址、同权限。Android 需公网 HTTPS，不能直接使用手机里的 `localhost` 指向电脑模型。

**“连接成功但格式不正确”、401/403、402、超时各意味着什么？**

- 格式不正确：服务能响应，但结果不符合笔记或助手需要的结构；核对准确模型 ID，尝试兼容模型或关闭不支持的页面图片。
- 401/403：密钥、权限或模型授权可能有问题。
- 402：可能余额或计费状态不足，按服务商信息核对。
- 超时/网络失败：检查网络、接口、服务商状态及页面大小，不能据此判断密钥正确或错误。

只使用 Chat Completions 兼容协议，不代表兼容任意服务商的所有独有接口。

**生成内容缺失、重复或不准确怎么办？**

对照原文核查。标题应在生成设置中指定，正文不要再次重复同名标题。旧智能笔记开头的重复标题已有显示兼容。缺失内容可调整标题/要求或重新生成该页，新结果会成为独立编号版本，不替换旧笔记。复杂公式与图片相关内容需要合适的模型能力。

**以前批量生成跳过已有笔记的页面，现在如何重做？**

从当前版本起，已有笔记不再跳过；重新运行会新增“版本 2、版本 3……”等独立笔记。旧内容保留。整份资料是逐页处理，不保证各页能推断跨页未提供的信息。

**助手能完全代替我操作所有东西吗？**

它能调用已开放的功能工具，但选择文件、输入密钥、点击下载/复制等需用户完成；精确手写和位置标注也适合手动操作。工具数量不代表所有真实模型都能正确规划所有请求。一次最多 12 步，长任务分批；停止不会撤回已成功保存的其他步骤。

**提示模型格式无效或负坐标导致导图失败怎么办？**

更新至 Windows 0.3.5 / Android 0.4.5 后，新导图坐标由软件负责，不再要求模型填写。格式错误会尝试结构化工具调用，并在继续任务时携带失败原因、保留成功记录。仍然失败可能是模型不支持所需输出、长内容截断或返回多项冲突操作；缩小单次范围或换用兼容模型，切勿把未执行当作成功。复杂大图可先建立概览，再补充节点。源码网页版更新后须重启本机服务，让后端加载新协议。

**助手失败后继续会不会重复创建？刷新后还能继续吗？**

当前会话保留执行记录和重复写入保护，可按“继续任务”接着做。刷新或退出会丢失该断点；已保存的笔记仍在。重新打开后先让助手查找、读取现状，再给明确要求，不要假定旧任务仍在后台执行。

## 常用容量限制

| 内容 | 当前限制 |
| --- | --- |
| 单份导入资料 | 100 MB |
| 单张笔记图片 | 5 MB，PNG/JPEG/GIF/WebP |
| 导图 JSON 导入 | 2 MB，500 节点、1500 条线 |
| 导图画布 | 最大 32000 × 32000 |
| 手写区高度 | 单区最高 3300，可另加区域 |
| AI 生成标题 | 1～12 个，每个最多 60 字，不重复 |
| Android ZIP 恢复 | 备份文件不超过 250 MB，解压内容还有大小检查 |

大文件或复杂页面在设备内存有限时仍可能失败；没有超过大小上限不等于任何设备都能顺畅处理。

## 保存、备份和隐私

**Windows、手机和网页会自动同步吗？**

不会。单独运行的本地资料库互相独立；公开部署时同一服务器账号的数据在服务器保存，也不会自动与独立 APK 或桌面本地资料库合并。没有实时多人协作和跨设备冲突合并。

**ZIP、HTML、导图 JSON 有什么区别？**

ZIP 用于资料备份；HTML 用于阅读/分享笔记；导图 JSON 用于继续编辑单张导图。Android 的 ZIP 恢复会替换当前资料库，Windows/普通网页暂无相同一键恢复入口。模型连接和密钥不在 ZIP 内。

**为什么关闭后内容没有保存？**

留意保存失败或网络/存储提示，错误未解决前不要关闭。网页版需后端服务可写且仍在运行；设备存储不足、浏览器清理、使用其他浏览器/账号、切换数据目录也可能表现为内容消失。先备份和核对位置，不要用空库覆盖原资料。

**资料会发给谁？**

手动编辑保存在当前本地或自建服务。启用 AI 后，请求需要的目录、文字、笔记和启用时的页面图片会发给你选择的模型服务商；自行部署时也经过相应服务器。模型设置在设备/浏览器内按保护口令加密，但运行中的 AI 请求仍需使用解锁后的密钥，不等于“永不离开设备”。

**如何报告问题？**

到 [Issues](https://github.com/kaituozher11-png/yuan-notes/issues) 写明平台/系统、版本、复现步骤、预期与实际结果、失败页码及不含密钥的错误截图。能提供不含私人信息的最小文件样例更有帮助。不要上传 API 密钥、口令、账户密码或未获授权的资料。


## 生成智能笔记提示“模型输出被截断”怎么办？

当前版本不在智能笔记的规划、正文或续写请求中设置 max_tokens 等固定输出长度上限，也不会要求模型压缩笔记。服务商仍可能限制单次输出；发生截断时，软件会保留原始内容并自动续写，续写仍不完整时按原有标题分段生成，全部完成后才保存一个新版本。旧笔记不会被替换，残缺结果不会写入。

若仍有失败页，点“仅重试失败页”，已成功的页面不会重复生成；点“重新运行”则按当前选择的完整范围再生成新版本。请保持联网、确认账户额度。自动续写和分段需要额外模型请求，耗时与费用由实际调用决定。为避免服务商反复返回残缺内容导致任务无限运行，单次请求失败恢复最多尝试三次续写，这不是笔记字数限制。

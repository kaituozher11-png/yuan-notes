# Agent 执行与恢复修复

对应 Windows 0.2.1、Android 0.3.1-offline（versionCode 10）和本地网页版。

## 问题与修改

此前读取原文后，模型回复一旦包含说明、JSON 代码块或不完整 JSON，就可能中断；已完成步骤的原文和执行记录没有作为可恢复任务保留。整份资料逐页读取也会较快消耗操作步数。

本次调整执行核心，保留已有软件功能，并提供 30 项具名操作：

- 兼容纯 JSON、带说明的 JSON、代码块、文本分块、原生 function/tool call；推理草稿不作为操作执行，冲突的多项指令也不直接执行。
- 优先使用 JSON 模式；服务商明确不支持该参数时退回普通请求。模型格式错误最多自动纠正两次，修复请求保留原任务和成功工具结果，不重新执行已完成操作。鉴权和网络错误不作为格式问题重试。
- 对话内保留任务断点、已读内容、成功操作和写入去重信息。失败或停止后可点击“继续任务”。同一写操作即使 JSON 属性顺序变化也不重复提交。
- 批量读取每批 1～5 页，标明每页截断或读取错误。要求全篇导图时，写入前检查原文覆盖记录，避免只读封面就保存所谓全篇导图。
- 文件选择等交互完成后可从原任务继续。刷新页面或重启应用会丢失会话断点，资料和已经保存的笔记仍保留。

## 验证

共 76 项自动测试通过，覆盖此前各项功能以及新增的回复兼容、格式恢复、JSON 模式退回、失败上限、鉴权错误不重试、取消、断点恢复、重复写入去重、页面读取边界、截断、全篇覆盖和人工交接。

使用隔离复制的实际 10 页答辩 PPT，以及模拟的模型服务完成以下流程，没有修改正式资料库，也没有调用用户真实密钥：

1. 先读取第 1 页，随后模拟连续三次不完整回复，复现截图中的中断。
2. 检查此时尚未创建笔记，界面提供“继续任务”。
3. 点击继续，成功读取第 2～6 页和第 7～10 页；第 1 页没有重复读取。
4. 接收带说明的 JSON，以及原生工具调用；保存一份独立导图笔记，包含 1 个中心节点、10 个页面节点和 10 条连接线。
5. 核对资料库只有一次创建记录，并打开刚保存的笔记。
6. 另一轮只模拟一次错误格式，自动纠正后直接完成全部步骤，无需手动重启。

安卓离线页面也使用本地 PDF 和模拟原生联网桥完成单次错误后的自动恢复、读取全部 10 页和保存同样的导图，手机宽度下未出现横向溢出。

## 验证边界

上述模型服务为模拟服务，用于验证协议兼容和实际读写链路，不代表所有真实模型对任意自然语言请求都能正确规划。未使用用户真实密钥验证该服务商，也没有实体 Android 设备测试。超过任务步数或上下文容量的资料需要分批处理。原有文件选择、密钥输入、下载授权等操作仍需用户完成；复杂 Word/MathType 的排版以原文件核对为准。

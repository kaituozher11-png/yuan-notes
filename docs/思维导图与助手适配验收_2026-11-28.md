# 思维导图改进与智能助手适配验收

日期：2026-11-28。版本：Windows / web 0.3.0，Android 0.4.0-offline（versionCode 11）。

## 解决的问题

原编辑画布固定，较多节点拥挤；导出使用固定边界且截取节点文字，扩大的节点和较长内容可能丢失。助手此前只支持整体替换导图区块，修改局部内容容易要求模型重写整张图。

现在支持可扩展画布、全屏和专注模式、缩放平移、触屏双指缩放、三种自动排版、节点和连接线样式、多选框选、成组移动与复制、撤销重做、折叠、搜索、SVG/PNG/JSON 完整导出和 JSON 导入。旧导图迁移保留画布尺寸、节点及自由连接。导出边界计入较长的连线说明，文字安全转义。

助手新增 configure_mindmap、edit_mindmap、export_mindmap，合计 33 项具名操作。局部编辑只提交变化字段，支持增删节点和连线、颜色、字号、形状、位置、文字、折叠、箭头和虚线。其余资料管理、混合笔记、生成、模板、关联批注、原文标记、便利贴、视图、复制及备份功能保留。文件选择、密钥输入及下载确认继续通过交互入口完成。

## 验证范围

这些结果只覆盖记录中的自动和人工场景，不是“所有情况下绝无 bug”的保证。未使用用户真实 API 密钥测试服务商的中文意图规划，未进行实体 Android 手机/平板及全新 Windows 环境安装验证。Android 下载保存窗口权限和厂商 WebView 差异仍需真机确认。浏览器内离线页面与原生下载桥的模拟不能替代完整真机测试。

一图上限 500 节点、1500 线，导入上限 2 MB；PNG 最长边 8192 且限制总像素，超大图适合 SVG。导图节点文字暂不支持数学公式结构化排版，公式仍可放在旁边笔记编辑区。自动布局解决节点重叠，不保证任意自由连接均无交叉。撤销历史和助手断点仅在当前会话保留。

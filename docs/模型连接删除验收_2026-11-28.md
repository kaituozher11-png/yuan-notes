# 模型连接删除验收

日期：2026-11-28。Windows / web 0.3.2，Android 0.4.2-offline（versionCode 13）。

## 修改

原“删除连接”仅在选中模型解锁后显示，导致未解锁的已保存连接无法直接管理。现在每行有独立删除按钮，未解锁也可操作，确认框显示连接名称。按钮与选择连接分开，不采用嵌套按钮。

删除时先保存当前设备/浏览器的新连接列表，再更新界面并清理该编号的解锁密钥、关联测试结果和编辑状态。删除当前连接后选择剩余第一条；删除非当前连接保持选择；删除最后一条显示空状态。资料和笔记不参与删除，也不撤销服务商的 API 密钥。生成、测试连接和助手任务期间禁止删除；正在解锁的连接被删除后，不允许解锁回调重新填入缓存。

## 检查

- 95 项既有自动测试全部通过，生产构建通过。
- 浏览器使用隔离数据和测试模型配置，验证未解锁删除、取消、同名不同编号连接、删除非当前连接、删除已解锁当前连接、剩余连接切换、最后一条删除及刷新后持久化。
- 对比资料库状态，删除前后资料与笔记不变。
- 模拟存储写入异常：保留配置和列表并显示删除失败。
- 模拟解锁尚未完成时删除：延迟回调不恢复已删除配置/密钥状态。
- 模拟助手请求持续运行：所有删除按钮禁用；停止任务后恢复。
- 320px 宽度下无页面横向溢出，删除图标保留可访问名称；无浏览器错误。

本次模型配置和密钥均为隔离的假数据，没有访问或删除用户实际保存的模型连接。没有进行实体 Android 设备复测；安装包的资源及签名核验与源码功能验证分别记录。

## 打包

Windows 和 Android 已重新构建，各自 94 个网页资源与生产构建逐字节一致。APK 签名验证通过，与旧测试版本一致。打包后的 Windows 客户端使用隔离的假配置，验证未解锁删除最后一条连接、持久化为空列表和空状态提示，没有浏览器错误。

# 源笔记预览版说明

本次 GitHub 发布提供项目源码、[图文安装与使用指南](https://github.com/kaituozher11-png/yuan-notes/blob/main/docs/使用指南.md)及两个测试安装包。首次使用请先阅读指南。网页端源码可在本机运行；公开多用户网站尚未部署。

## 下载文件

- [YuanNotes-Windows-Setup-0.1.2.exe](https://github.com/kaituozher11-png/yuan-notes/releases/download/preview-2026-11-20/YuanNotes-Windows-Setup-0.1.2.exe)：Windows x64 本机预览安装包，未进行数字签名。导入 Word、PPT 和 PDF 时需要系统可用的文档转换工具，具体要求见仓库 [README](https://github.com/kaituozher11-png/yuan-notes#readme)。
- [YuanNotes-Android-offline-0.2.3.apk](https://github.com/kaituozher11-png/yuan-notes/releases/download/preview-2026-11-20/YuanNotes-Android-offline-0.2.3.apk)：Android 离线测试版。支持在手机本地导入 PDF、阅读和记笔记；智能生成需要联网并自行配置模型接口。Word 和 PPT 原版式导入不在此 APK 中提供。

## 验证范围

源码的 48 项自动测试与网页生产构建已在本机通过。安装包是测试版本；Android 0.2.3 尚未完成实体平板复测，Windows 安装包也未在无开发工具的全新电脑上完整验收。真实模型服务商的连接与生成效果取决于用户自己的接口、网络与额度，本次发布未代用户完成这些服务商测试。

安装前请备份现有资料。当前没有自动更新、多设备同步或应用商店版本。

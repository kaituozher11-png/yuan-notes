## 本版内容

保留批量导入、文件夹、原文阅读与文字复制、混合笔记、公式、图片、手写、关联批注、画笔、便利贴、模板、AI 自定义生成标题、回收站、导出和备份。

本版新增可选“不使用模板 · 按内容组织”：先读每页、独立拟题再生成，不把固定六段套用全部页面；仍可选择模板和自定义标题。每页通常两次模型请求，费用和耗时可能增加。

导图新增两侧紧凑布局、紧凑美化、分支颜色和层级字号，新图自动整理；助手按知识逻辑组织分支，旧图点击美化即可整理，不自动改写原有内容。

本版保留思维导图：大画布、全屏/专注模式、缩放平移、三种布局、多选移动与复制、折叠搜索、撤销重做、SVG/PNG/JSON 导出与 JSON 导入。助手新增局部编辑导图、调整画布/布局和导出，共提供 33 项具名操作。完整功能见[首页](../README.md#功能介绍)。

## 安装与升级注意

- Windows 包未数字签名，PDF/Office 处理工具需另装；普通安装用户不需安装 Node.js。
- Android 为测试签名 APK，PDF 本地处理，无需连接电脑或特定 Wi-Fi。Word/PPT 请先转 PDF。
- 先备份再升级；Android 优先覆盖安装，卸载或清除数据会影响本地资料。自己重编译的 APK 签名可能与发布包不同。
- 没有自动更新、自动跨设备同步、官方公共网址、iOS 包或应用商店上架版本。网页源码需自行运行服务。
- 阅读和手动笔记不需要模型；智能功能需联网和自有 API，调用可能产生费用。

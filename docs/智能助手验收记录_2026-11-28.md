# 智能助手验收记录

日期：2026-11-28。对应 Windows 0.2.0、Android 0.3.0-offline（versionCode 9）与网页版。

## 实现范围

共提供 29 项具名操作，覆盖资料和笔记检索、原文读取、页面定位、文件夹管理、资料移动/命名/回收/恢复、笔记创建/复制/修改/排序、混合内容编辑、区块排序与删除、原文关联和混合批注、画笔/荧光笔/橡皮擦、便利贴、智能笔记生成与对比替换、模板管理、导出/备份/复制及阅读布局。需要文件选择或敏感输入的功能打开现有入口继续完成。

网页与桌面复用已有服务商连接；Android 复用现有原生联网桥。共享协议验证器和执行器限制操作名称及参数；所有读写仍经过当前用户的既有接口，无法凭空引用其他用户的资料。资料与工具结果作为数据传入对话。循环按“决策—执行—观察结果—再决策”运行，最多 12 步。

修改和删除操作的确认展示具体对象；生成覆盖展示原有笔记和新草稿。写入前保存待提交笔记，检查目标是否存在以及内容是否已变化。相同写操作在同一次任务中重复返回时拦截。失败和停止保留已经完成的操作，不声称整体事务已回滚。

## 自动验证

完整测试共 68 项通过。新增覆盖协议格式/输出截断/超长输入、模型请求与错误密钥遮蔽、全部具名工具、混合文字公式图片与独立导图、图片尺寸对齐、节点形状和连接线、手写笔迹、原文批注、便利贴移动与隐藏、模板、对比替换、防陈旧覆盖、取消确认、重复写操作、步骤上限、连续失败、停止，以及公共模式鉴权和模型目标地址限制。

集成测试启动隔离的真实应用服务和模拟模型服务，通过 `/api/assistant/turn` 完成创建文件夹、移动资料、创建含文字/公式/图片的笔记和添加公式批注，并核对磁盘保存结果及复制笔记后内容保留。

## 浏览器验证

使用隔离测试资料和模拟模型完成以下流程，没有修改正式资料库：

- 网页读取 PDF → 创建复习笔记 → 写入公式与独立思维导图 → 打开笔记。
- 追加内容 → 撤销 → 重做，检查实际保存的内容相应变化。
- 读取标记并添加隐藏便利贴；取消删除资料后资料保留。
- 停止延迟模型请求后没有执行其返回的写操作。
- 网页与离线页面分别创建文件夹并将资料移入。
- 离线页面通过模拟原生桥完成模型调用、读取本地 PDF、创建混合笔记；图片上传后作为引用插入原有编辑区。
- 模拟断网时提示“智能助手需要联网，请联网后重试”。
- 对话中的导出按钮可触发笔记下载；导入命令打开原有批量导入窗口并提示继续交互。
- 检查 1280px 电脑、390px 手机及 820px 平板宽度；平板上输入区可见，无助手栏横向溢出。

## 交付与验证边界

网页正式构建和 Windows/Android 包构建通过；包内网页资源与正式构建逐文件校验。Android 使用此前测试版相同的签名，支持覆盖更新。Windows 安装包未签名，APK 仍为调试签名测试版。

没有使用用户真实密钥进行实际厂商模型测试；模拟模型验证操作链与持久化，不能证明所有实际模型都能正确理解任意指令。没有连接实体 Android 手机/平板，未完成真机测试；也没有在全新 Windows 电脑上验证安装向导。助手不能承诺任意自然语言任务都能自动完成；不支持的操作或无法确认的目标需要补充说明。

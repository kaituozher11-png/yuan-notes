# 智能笔记截断恢复验收

日期：2026-11-28。Windows / web 0.3.5；Android 0.4.5-offline（versionCode 16）。

## 问题与修改

旧实现将每页正文限制为 3500 token、自动提纲限制为 1000 token。模型返回 length / max_tokens 时直接失败，所以十页资料可能只有部分页面完成。

根据用户“不限制”的要求，智能笔记的连接测试、提纲、正文及续写请求均不再发送 max_tokens、max_completion_tokens 或 max_output_tokens，不用更短的正文替代用户想要的内容。服务商仍有自己的单次输出和上下文上限，软件不能解除这些限制。

发生截断时，保留已收到的原始 JSON、中文和公式，并携带同一页原文与图片请求从断点续写；没有正文、只有模型推理消耗的截断响应也会重新尝试。每次请求最多三次续写，防止服务商反复返回残缺结果导致无限请求。这限制的是故障恢复次数，不是笔记字数。

续写仍失败时，多标题笔记按原有标题依次分段生成，不删减标题，不压缩正文；旧六字段格式也分别生成后合并。全部区块完整才保存一个新版本；任意区块失败不写入部分结果、不替换旧笔记。单标题无法完成时保留失败状态，提供“仅重试失败页”。

生成对话框新增“仅重试失败页（数量）”，成功页不重复生成；“重新运行”仍按当前选择的完整范围新增版本。按钮在窄屏自动换行，并拦截重复启动同一生成任务。

## 自动测试与接口验证

111 项自动测试通过，正式构建通过。新增覆盖：

- JSON 结构、中文字符、字符串、LaTeX 反斜杠和公式中途截断后的精确拼接。
- 多次续写、空推理截断、看似完整但被标记截断的响应、服务商拒绝、内容拦截、无效格式、取消和持续截断。
- 模板和逐页自适应笔记保留标题顺序、正文与公式；分段中某项为空、缺失、取消或再次失败时整页不保存。
- 实际 HTTP 模型适配器所有智能笔记阶段均不含输出长度参数；自动提纲、续写和连接测试可恢复。
- 实际笔记 API 完成续写后只保存一个编号版本，重复生成继续编号；失败不新增版本，旧正文和用户补充逐项保持不变。

## 页面与 Android 离线流程

在隔离浏览器使用有效三页 PDF 与模拟 Android 模型桥：

1. 整份生成时第 1、3 页通过续写成功，第 2 页持续截断；界面显示 2 页成功、1 页失败。
2. 恢复模型后点“仅重试失败页”，只请求第 2 页，最后三页均有版本 1；第 1、3 页原有笔记对象保持不变。
3. Android 离线保存路径验证整页持续截断后按三个标题分段。每段 13200 字符（含 LaTeX），共七次请求，只保存一份新版本，原文与页面图片在各次请求中一致，正文没有截短。
4. 分段再次失败时，前一次成功笔记和整个笔记列表保持不变。
5. 320px、390px 下生成对话框操作按钮均在内容区内，390px 截图人工检查通过，浏览器无脚本错误。

## 安装包与正式资料

Windows 与 Android 安装包分别有 94 个网页资源，与最终构建逐字节一致。Windows 包内新增共享续写模块与源码一致，实际启动打包服务并使用 PDF 测试公式续写、版本 1/2 和旧版本保留。APK 签名校验通过，与此前测试包一致。

本机网页服务已备份资料状态后重启。重启前后 12 份资料、35 份笔记及 3 个文件夹的完整状态一致，未改变用户内容。

本轮使用模拟模型检查传输、恢复和保存行为，未调用用户真实密钥，也未进行实体 Android 设备测试。自动续写和分段会增加模型调用次数、耗时和实际费用。网页版刷新后可用，已安装客户端需覆盖安装本次新版。

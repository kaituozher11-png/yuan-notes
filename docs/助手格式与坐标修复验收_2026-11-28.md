# 助手格式兼容与导图坐标修复验收

日期：2026-11-28。Windows / web 0.3.3，Android 0.4.3-offline（versionCode 14）。

## 截图对应问题

第一张截图是模型连续返回不符合操作协议的内容，软件在最多两次纠正后暂停。此前纠正会把错误输出追加进对话，下一次“继续任务”也没有携带上次失败的结构化原因；模型可能再次输出同样过长、不完整或不合规范的内容。没有原始服务商响应，不能仅凭截图认定该次究竟是截断还是哪个字段不正确。

第二张截图包含“坐标负值”线索。创建导图本应由软件自动排版，但旧校验先要求模型坐标非负，因此在排版前就失败，属于输入规则和自动布局职责不一致。

## 修改

- 首次仍使用兼容 JSON 的模式；格式失败后尝试一个 `yuan_notes_action` 原生工具调用，工具可表达单个功能操作或 `tool:null` 的回答/询问。服务商明确拒绝 tools/tool_choice 时退回 JSON 纠正，不将鉴权或网络问题当格式问题重试。
- 最多两次格式纠正，错误草稿不再作为成功历史追加，原任务与成功结果保持。遇到截断强调缩短内容及分批提交，并显示更具体原因；不把不完整回复、多个冲突操作、推理草稿或未知命令当作执行成功。
- 对单项完整操作兼容序列化的 args，以及无歧义的 arguments 字段。原生包装同样经过原有具名工具和执行前校验。
- “继续任务”检查点携带失败原因、成功读写和重复写入记录；工具第三次失败的结果也先保存到检查点再停止。
- 新建/追加导图只需节点与连线，模型的坐标忽略，由软件紧凑布局。给已有图新增节点可省略坐标；修改已有节点仍严格验证位置和尺寸。空节点、重复编号、无效端点和超大数据继续拦截。
- 重复写入签名忽略新图中不参与排版的坐标，防止模型仅改坐标后再次创建同一导图。

## 自动检查

102 项测试全部通过，网页生产构建通过。新增覆盖：

1. 结构化调用、字符串化参数、公式反斜杠；未知工具、数组与多操作冲突仍拒绝。
2. JSON 格式失败转原生工具、原生工具被拒后退回、截断上限、鉴权不重试、不保留错误草稿。
3. 检查点继续携带失败原因，成功读取不重复；仅改变新图坐标的重复提交不再保存。
4. 新图负坐标、缺失/过大坐标与已有节点越界修改的区别；新图软件排版，旧节点越界仍失败。
5. 实际 API 与模拟模型：导入 10 页 PDF，读取 10 页及已有智能笔记，模拟连续格式失败；继续后转原生调用，成功追加负坐标/无坐标混合导图；重复提交被拦截，导图仅一份，智能笔记和个人补充保留。
6. 失败结果（三次均失败）的完整检查点保存。

## 界面检查

在隔离的 Android 离线页面和原生联网桥模拟中，用实际 10 页 PDF，执行批量读页、补读被截断的第 10 页、读取已有笔记、格式失败、点击“继续任务”、原生调用和保存导图。核对只保存一张 3 节点图，原智能笔记和补充保留；390px 无页面横向溢出，没有浏览器错误。补读步骤说明全篇覆盖保护仍生效，不会把截断当已读完。

## 边界

模拟模型验证协议、数据和界面链路，不能代替真实服务商的中文理解与生成质量测试。本次未使用用户真实密钥，也没有实体 Android 手机/平板复测。服务商不支持结构化输出或持续返回错误时，任务仍会明确暂停，不承诺任意模型永远成功。长篇资料和大图可分批，原有任务步数及内容长度上限保留。

源码网页版后端需重新启动才能加载新协议；仅刷新前端不能替换已经运行的旧后端模块。新版安装包须安装并重新打开后使用。

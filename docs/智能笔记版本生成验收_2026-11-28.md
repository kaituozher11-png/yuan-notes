# 智能笔记编号版本验收

日期：2026-11-28。Windows / web 0.3.4，Android 0.4.4-offline（versionCode 15）。

## 修改原因与行为

旧批量任务跳过已有智能笔记，单页重做走预览替换，导致截图里的“重新运行”仍全部跳过。现在当前页、指定页、整份文件及助手生成均新增独立笔记，不再因旧笔记而跳过。

标题示例：“第 1 页 · 智能笔记（版本 1）”“第 1 页 · 智能笔记（版本 2）”。版本号按资料和页码单独递增；旧数据没有版本号时仍计入已有版本，不改写其标题、正文、个人补充或关联。删除版本后不复用编号；备份恢复的较高版本也计入后续编号。

新版本是独立笔记，不自动复制用户在旧版中的个人补充；这些内容完整保留在旧版，可在笔记下拉框切换查看。助手的预览草稿提交也改为新增版本，旧笔记在预览期间被编辑时不会遭到替换；草稿不能重复提交。

资料库统计按“已有智能笔记的不同页码”计算，避免一页多版本错误地把全文件标为生成完毕。界面分别显示处理页数、新增页数及失败原因，停止时不误报全部完成。

## 自动测试与集成

104 项自动测试全部通过，生产构建通过。

- 旧智能笔记、用户改过的标题、个人笔记及关联保持不变；多次生成均为新 ID。
- 同页连续版本 2～12、不同页从版本 1 开始，已删除和恢复高版本不复用编号。
- 多版本只算一个已生成页，删除一页全部版本后该页不再计为已生成。
- 实际 API + 模拟模型验证直接重做、预览另存、单次草稿提交、两次并发生成的独立版本号、失败不写入、删除后继续编号。
- 助手调用同一页生成两次，实际保存版本 6、7，旧笔记及个人补充仍保留。
- 页码、资料不存在或已删除等边界拒绝写入；先前所有格式恢复、导图、账号隔离等测试继续通过。

## 界面与离线

在隔离 Android 离线页面使用实际 10 页 PDF 和模拟原生模型桥：

1. 整份文件生成一次，得到每页版本 1，共 10 份。
2. 点击“重新运行”，每页新增版本 2，总计 20 份；逐份核对版本 1 未改变。
3. 指定第 1 页再生成，新增版本 3，总计 21 份；下拉框显示版本 1、2、3，选中新版本。
4. 刷新后 21 份仍在，资料库显示“已生成 10/10 页”，没有显示 21/10。
5. ZIP 备份和恢复后内容、版本号全部一致；390px 没有页面横向溢出，浏览器无错误。

## 包与边界

Windows 和 Android 包已重新构建，各自 94 个网页资源与构建逐字节一致；Windows 包含新增版本模块，实际服务启动与助手协议检查通过。APK 签名与旧测试版一致，可覆盖安装。

版本数越多会增加存储、导出体积和模型费用，重复点击是新的生成任务。此处使用模拟模型验证数据流，不代表真实模型质量；未使用用户真实 API 密钥，也没有实体 Android 设备复测。源码网页版需重启后端加载新增保存逻辑；只刷新前端不能替换旧后端。更新前建议备份，更新不会自动删除旧笔记。

本机正式网页服务已备份资料状态后重启，加载新增保存逻辑；重启前后核对 12 份资料、30 份笔记的编号及标题、正文、个人补充、关联和删除状态一致，没有修改旧笔记。

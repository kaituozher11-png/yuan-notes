# 智能笔记重复标题修复

日期：2026-11-24。对应 Windows 0.1.5、Android 0.2.6-offline。

## 原因与修改

智能笔记界面已经显示每个区块的标题，但模型偶尔在该区块的 Markdown 正文开头再次返回同名标题，导致视觉上重复。

- 生成要求明确说明正文不重复区块标题；网页服务端与 Android 离线端共用结果规范化逻辑，保存新结果前移除正文开头的重复标题。
- 已保存的笔记在阅读、草稿对比和导出时自动处理重复标题，无需重新生成，也不自动覆盖原始保存内容。
- 仅处理正文开头与区块标题相同的独立标题行；兼容 Markdown 标题、加粗标题、纯标题和 Setext 标题，以及连续重复的标题。
- 保留不同的小标题、正文中间的标题、公式、图片和正文内容。编辑状态继续读取原始正文，避免输入时自动删改内容。

## 验证

- 57 项自动测试全部通过；增加重复标题回归测试，覆盖新生成结果、已保存结果、旧版数组笔记、重复多次、空正文、换行差异、公式、代码和缩进保留。
- 网页正式构建通过。
- 复制用户第 6 页的已保存智能笔记到隔离测试资料库，在电脑和 390px 手机宽度下验证：4 个区块各显示一个标题，7 处公式正常渲染。
- 对同一份笔记执行实际 HTML 导出，4 个区块各有一个标题，保留 7 处数学公式。
- 新版 Windows 与 Android 安装包包含此修复；Android 包内 90 个网页资源与本次构建逐个校验一致，签名与此前测试版相同。

本次未使用真实大模型重新生成笔记；生成结果处理通过自动测试验证。当前没有连接实体 Android 设备，未完成真机复测；Windows 未在全新电脑上验证安装向导。

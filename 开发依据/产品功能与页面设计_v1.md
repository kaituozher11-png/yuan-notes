# 源笔记：产品功能与页面设计（讨论稿 v1.1）

## 1. 产品定位

面向学生的“资料与笔记并排学习”工具。学生导入课件或讲义后，可以按原文档的页或幻灯片生成有出处的学习笔记，再用文字、手写、公式、图片和思维导图补充自己的理解。资料与笔记之间的链接应能双向跳转，并在同一屏幕对照查看。

本稿是产品设计依据，不包含技术选型、实现代码或 AI 提示词。默认先设计个人使用场景，重点考虑电脑和支持手写笔的平板；手机提供阅读、检索和轻量编辑。

**AI 使用前提**：学生自行接入可用的大模型 API，并自行承担相应服务商的调用费用。未配置模型时，资料阅读、个人笔记、链接和模板仍可使用；AI 生成入口显示配置引导。应用不内置默认可用的付费模型账户。

### 设计原则

1. **原文可核对**：生成内容明确指向文档页；提取不清、资料未写明的内容应标注，不把推测写成原文事实。
2. **个人笔记可保留**：重新生成只更新 AI 草稿，绝不覆盖学生自己写的文字、笔迹、图片或链接。
3. **少切换页面**：默认同时显示资料与笔记；允许一键放大任意一侧。
4. **先能记，再丰富**：录入文字、手写、公式等操作应直接发生在笔记页内，不依赖复杂的模式切换。

## 2. 内容组织

```text
资料库
└─ 学科 / 课程（可选）
   └─ 文档（PDF、PPT/PPTX、Word/DOCX）
      ├─ 原文第 1 页 / 第 1 张幻灯片
      │  ├─ 对应的 AI 笔记主页
      │  └─ 我的补充页（可多页，可调整顺序）
      ├─ 原文第 2 页 / 第 2 张幻灯片
      │  └─ ...
      └─ 跨页笔记（例如某一章总结，可链接多处原文）
```

- **原文页**是稳定的学习定位单位。PDF 按页、PPT 按幻灯片、Word 按导入时生成的预览页组织；Word 文档修改或重新排版后，页码可能变化，系统应保留旧版本并提示核对链接。
- **AI 笔记主页**与一页原文对应，包含生成内容和来源标记。学生可以修改其正文，但重新生成时必须先展示差异并确认替换范围。
- **我的补充页**可从对应笔记下方新建，适合课堂补充、习题、推导、错题等。它默认继承所属原文页，也能另加多个原文链接。
- **跨页笔记**用于章节总结、知识串联；不强行归到某一页，允许链接同一文档或不同文档的多处内容。
- 文档、原文页、笔记页、笔记内的段落或对象均有独立身份。用户重命名笔记或调整其顺序时，链接仍应有效。

## 3. 功能设计

| 模块 | 用户可做的事 | 关键规则或状态 |
| --- | --- | --- |
| 资料导入 | 拖入或选择 PDF、PPT/PPTX、Word/DOCX；填写课程、标题、标签 | 展示文件页数、处理进度和失败原因；首版优先保证 PDF/PPTX/DOCX，旧版 PPT/DOC 可引导转换后导入 |
| 模型连接 | 添加、测试、切换自己的模型 API；选择用于笔记生成的模型 | 显示连接状态、支持能力和费用归属；密钥始终隐藏，不能随文档或笔记导出 |
| 原文阅读 | 翻页、缩放、目录跳转、搜索原文、选择文字或框选区域 | 图片化页可阅读；文字提取失败时明确显示，允许只建立页级链接 |
| AI 生成代理 | 使用学生选定的模型，按页提取证据、生成结构化笔记、核对来源并标记疑点 | 生成当前页、选定页或整份文档；可查看进度、停止、重试；失败页不影响已完成笔记 |
| AI 笔记 | 阅读每页摘要、概念、重难点、易错点、公式说明、复习问题 | 每项尽量标注对应原文位置；证据不足时显示“资料未明确说明”或“需人工核对” |
| 个人笔记 | 新建、复制、重命名、排序、删除补充页；输入文字、手写、公式、图片、思维导图 | 自动保存；提供撤销/重做、删除恢复和最近修改状态 |
| 双向链接 | 从原文选中内容链接到笔记对象；从笔记反向链接原文页或区域 | 点击后在另一侧定位并短暂高亮；链接失效或位置不准时可重新指定 |
| 模板 | 选择默认模板；建立课程或个人模板；调整笔记区块及顺序 | 已有笔记不会因模板修改而自动重排；应用到旧笔记前预览变化 |
| 查找与整理 | 按课程、文档、标签、关键词查找；筛选“未生成/待核对/我的笔记” | 搜索结果能直达对应原文页或笔记页，保留双栏上下文 |
| 输出与备份 | 导出单页或整份笔记、连同来源页码的打印版；备份资料和笔记 | 导出时区分 AI 内容与个人内容；链接在应用内可点击，打印版保留可读页码 |

### 3.1 每页 AI 笔记的默认结构

1. **这页讲什么**：用简短语言概括主题，与前后页关系明确时再补充。
2. **核心概念与结论**：逐条列出定义、结论及其适用条件。
3. **重点与难点**：说明为何重要、难在哪里；可由学生标记“我已掌握/待复习”。
4. **易错点与注意事项**：区分原文明确提醒、根据内容推导的学习提示、信息不足的待核对项。
5. **公式、图表或例题解读**：只在原页确实存在时展示；保留符号和单位，附来源位置。
6. **快速自测**：1 至 3 个可依据本页回答的问题，可折叠答案；不凭空加入原文之外的结论。
7. **我的补充**：独立的可编辑区域；生成操作不触碰这里。

一页内容很少时，不强求填满以上栏目。遇到扫描件、复杂图表或识别不确定的公式，显式标记“待核对”，让学生快速回看原文。

### 3.2 自备模型 API 与笔记生成代理

**模型连接**采用“用户自带密钥”的方式。学生可建立多个连接配置，每个配置填写服务商或自定义接口地址、API 密钥和模型名称；设置一个默认模型，也可在生成任务开始前临时切换。连接测试要反馈“可连接、密钥无效、模型不可用、额度不足、接口不兼容”等可理解的状态。测试本身可能产生少量调用费用，界面应提前说明。

连接配置还要标明模型是否支持图片输入、长文档输入等能力。纯文本模型可处理已提取的文字；扫描件、复杂图表和公式页若缺少可靠的文本识别或视觉模型，则提示“此页需要可处理图片的模型或人工核对”，不能假装已经完整理解。不同服务商的接口和能力不完全相同，首版只承诺经过适配和测试的连接方式；自定义接口在验证通过后使用。

这里的 **agent** 是受控的学习任务流程，而不是可以自行改写资料的开放式助手：

1. **准备页内容**：识别页码、可提取文字、图表与公式的位置，建立可回看的原文片段；必要时使用识别能力处理图片化页。
2. **组织生成任务**：按所选页和笔记模板逐页处理；根据页内容与模型能力决定传入文字还是图片，并避免无关页占用额度。
3. **生成笔记草稿**：生成摘要、概念、重难点、易错点、公式解读和自测问题，并给出对应原文页及可定位的片段。
4. **检查与标记**：核对页码和引用片段是否确实存在；找不到来源、内容相互矛盾或识别不清时标记“待核对”。这一步不能保证结论全部正确，最终仍由学生对照原文确认。
5. **交付与续跑**：按页保存草稿和状态；允许暂停、继续、重试失败页。学生的手写、文字补充、图片、导图和已确认链接都不被代理修改。

生成前显示待处理页数、所选模型、将发送的内容类型（文字/页面图片）及费用可能由模型服务商收取；有能力时给出粗略用量估计，不承诺精确账单。首次向某一服务商发送资料前，明确提示资料会离开当前设备。生成中展示每页进度与失败原因，允许停止后保留已完成页。

密钥只用于连接所选模型，不写入笔记、导出文件、共享内容或诊断日志；显示时仅保留掩码，并支持替换和删除。网页形态下需规划安全的凭证存放与请求通道，不能仅把密钥明文保存在浏览器页面中。断开或删除模型连接不会删除已生成的笔记。

后续可在同一代理流程上增加“解释选中的原文”“根据指定页回答问题”等能力，但回答也必须带来源；首版以按页生成可靠笔记为重点，无需设计多个互相对话的代理。

### 3.3 个人笔记的编辑体验

- 笔记页采用**纵向区块**：正文、手写区、公式、图片、思维导图都可作为区块插入、移动、折叠和删除。文字区支持标题、列表、表格、引用及行内公式；公式区支持可视编辑和常见数学符号输入。
- 手写区提供笔、荧光笔、橡皮、套索、颜色及粗细；触屏设备支持手写笔与手掌误触处理。电脑可以鼠标绘写，但以打字为主。笔迹作为原生对象保存，不仅是一张截图。
- 图片可粘贴、上传、拖入、调整尺寸并加说明。思维导图支持添加/移动节点、连线、折叠分支、节点跳转到来源；可在笔记中预览，点开全屏编辑。
- 新增笔记页时，可选择“空白、课堂笔记、公式推导、错题记录、思维导图”等模板。提供明确的页面标题与所属原文页，避免长文档中迷失位置。

### 3.4 原文与笔记的链接

- 链接分三级：**页级**（最稳定）、**文字/段落级**、**区域级**（图、表、手写圈选等）。用户先选原文位置，再选已有笔记内容或新建笔记；反向操作也成立。
- 一处原文可链接多个笔记；一条笔记也可链接多处原文。笔记里的链接以小型来源标记显示，原文页侧边显示对应的笔记标记，避免大量连线遮挡内容。
- 点笔记来源：原文侧跳到对应页并高亮目标；点原文标记：笔记侧定位相应段落。默认仅移动另一侧，当前侧的浏览位置尽量保留。提供“返回上次位置”。
- 开启“跟随翻页”时，切换原文页会切到其 AI 笔记主页；关闭后两侧可独立浏览。若正在编辑未保存内容，翻页不丢失输入。
- 文档重新导入或更新后保留旧版本。对无法自动确认的细粒度链接标记“位置待核对”，用户可查看旧页并手动重连；页级关系仍可用于定位。

## 4. 页面与布局

### 4.1 资料库首页

首屏直接进入资料库。顶部为全局搜索、导入资料和账号/设置；左侧为“最近学习、全部资料、课程、模板、模型连接、回收站”；中间按最近打开及课程展示文档列表。每项显示标题、类型、页数、AI 生成进度、最近学习页和待核对数。点击文档直接回到上次学习位置。

空资料库只展示一个明显的“导入资料”入口及支持格式，不做宣传式首页。导入处理中，文档仍可打开已完成的页。

### 4.2 文档学习页：核心工作台

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 课程 / 文档名       搜索      生成笔记     布局切换      更多             │
├──────────────┬─────────────────────────┬─────────────────────────────────┤
│ 页码与笔记树  │ 原文                    │ 笔记                            │
│              │ [上一页]  12/48 [下一页]│ 第 12 页笔记  [AI/我的补充]     │
│ 11 主题 A    │                         │ 这页讲什么 / 重难点 / 易错点     │
│ 12 主题 B ●  │ PDF 页 / 幻灯片 / Word 页 │ 公式 / 自测 / 我的补充           │
│  ├ AI 笔记   │                         │                                 │
│  ├ 课堂补充  │ [选中文字或圈选区域]    │ [+ 新增笔记页]                  │
│  └ 错题     │                         │                                 │
│ 13 主题 C    │                         │ 编辑工具：文字 手写 公式 图片 导图│
├──────────────┴─────────────────────────┴─────────────────────────────────┤
│ 保存状态 / 处理进度 / 链接待核对提示                                    │
└──────────────────────────────────────────────────────────────────────────┘
```

- 默认**左树 + 原文 + 笔记**。左树可收起；原文与笔记之间可拖动分隔，比例记住个人偏好。原文一侧以可检查内容的尺寸显示，不因旁栏而过度缩小。
- 顶部的布局切换有“并排、只看原文、只看笔记”。只看某侧时，另一侧保留可点开的窄入口；从链接跳转可暂时展开双栏。
- 原文工具集中在原文上沿：页码、缩放、适应宽度、目录、选取链接。笔记工具靠近编辑位置：插入内容、撤销/重做、模板。生成按钮只出现在文档或页的上下文中；点击后先确认页范围、模型和发送内容，再启动任务。
- 当前页与当前笔记页可以不同。顶栏同时标明两侧位置；开启跟随翻页时再同步切换。
- 常见屏幕上，导航树建议约 220 至 280 像素；收起后把空间让给阅读。双栏默认各占剩余区域约一半，允许调节。

### 4.3 平板与手机

- **平板横屏**：保留双栏，导航树改为可展开抽屉；手写时笔记侧可放大为主画布，原文保留窄预览或一键返回。
- **平板竖屏**：默认上下分栏，原文在上、笔记在下；可切换单栏，并用固定的“原文/笔记”切换控件跳转。手写工具悬浮在笔记区边缘，不遮挡笔迹。
- **手机**：默认单栏，顶部页码和“原文/笔记”两个视图；点击来源后切换视图并定位，提供返回按钮。支持阅读、文字、图片和轻量公式编辑；大幅手写与思维导图编辑给出全屏画布。

### 4.4 模板管理页

左侧是个人与课程模板列表，中间是实时笔记预览，右侧是设置。可增删和排序区块、配置字段提示、选择标题层级、颜色及页面纸张/网格样式，分别指定 AI 区和“我的补充”区的默认位置。保存前可预览到一页真实资料；应用范围可选新建笔记、当前文档或指定课程。模板只决定布局和提示字段，不改变原始资料与已有链接。

### 4.5 模型连接与生成任务页

模型连接页以列表展示已配置的连接名称、模型、可用状态、视觉能力及默认标记。右侧编辑区填写接口地址、模型名称和密钥，提供“测试连接、设为默认、替换密钥、删除连接”。密钥输入框默认隐藏内容，不显示完整密钥；页面同时说明调用费用由模型服务商收取。没有连接时，只显示简明的添加入口和手动笔记仍可使用的状态。

从文档学习页点击“生成笔记”，弹出任务确认面板：选择当前页/指定页/整份文档、模型连接、模板；展示预计发送的页数及文字或图片内容类型，再由学生启动。任务运行后可在同一面板查看逐页状态、停止与继续；关闭面板不应中断任务。需要用户处理的连接错误在此处提供直达模型连接页的入口。

## 5. 典型使用流程

1. **首次设置**：添加自己的模型 API，测试连接，确认模型能处理讲义中的文字或图片；未完成设置时仍可导入和手动记笔记。
2. **课前整理**：导入讲义，等待页预览出现；选“整份生成”或先生成重点页，确认模型、页范围和发送内容后启动代理；在资料库查看哪些页已完成、哪些页需要核对。
3. **课堂对照**：打开第 12 页，右侧显示对应 AI 笔记；在某个公式旁添加“公式推导”补充页，输入公式和手写推导，圈选原文公式建立链接。
4. **课后复习**：按课程搜索“易错点”，打开命中笔记；点击来源，原文和笔记并排定位；完成自测后标记已掌握或待复习。
5. **复用模板**：为数学课调整“定义、定理、证明、例题、我的推导”模板，仅应用于以后新建的笔记；已有内容保持原样。

## 6. 状态与异常处理

- **导入/生成中**：按页显示“等待、处理中、完成、失败”；生成中可阅读和编辑已经完成的页。停止任务不删除已完成笔记。
- **无模型或模型不可用**：无连接时引导配置；密钥失效、余额不足、限流、网络断开或模型不支持图片时说明具体原因，并允许更换连接后从失败页继续，避免重复消耗已完成页的额度。
- **无可提取文字**：展示原图和识别状态；允许手动记笔记及建立页级/区域级链接。无法确定的识别结果不默认为准确。
- **AI 输出有误**：学生可修改、标注“待核对”、查看对应原文并重新生成该页。重新生成提供预览与差异，不直接覆盖学生内容。
- **离线或同步失败**：已有资料和笔记尽量可读可编辑；显示本地保存状态和待同步状态。多设备冲突时保留两个版本供选择。
- **误删**：笔记页、区块与文档进入回收站；删除原文前提示其关联笔记与链接数量。撤销、自动保存和版本记录应覆盖主要编辑操作。
- **隐私**：使用 AI 前说明资料会发送到所选模型服务商；私有资料默认不公开分享。密钥不随笔记同步、导出或共享；导出、备份、清除资料要有清晰入口。

## 7. 建议实施顺序

| 阶段 | 交付范围 | 能完成的学习闭环 |
| --- | --- | --- |
| 第 1 阶段：可用核心 | PDF/PPTX/DOCX 导入与稳定预览；自备模型 API 配置和测试；受控的按页生成代理与来源核对；AI 笔记主页；文字/图片/公式补充页；页级双向链接；双栏与单栏切换；自动保存、搜索 | 用自己的模型从课件一页生成可核对的笔记，再从笔记回看原文 |
| 第 2 阶段：完整创作 | 手写笔工具；文字/区域级链接；基础思维导图；个人与课程模板；平板优化；导出与恢复 | 覆盖题目中全部主要创作方式和精确对照 |
| 第 3 阶段：增强 | 复杂版式/OCR 优化；跨文档知识关联；更细的模板样式；离线与多设备同步完善；学习进度统计 | 提升复杂资料处理质量与长期使用体验 |

首版应以真实的 PDF、课件、Word 讲义各取一份检验：模型连接可测试，密钥不会出现在导出资料中；页序正确、公式/表格可读；生成内容有可点击来源；额度或网络错误可从失败页继续；个人笔记不会被重新生成覆盖；链接往返定位准确。完成这些再扩展内容生成形式，避免功能很多但学习时无法核对原文。

## 8. 后续需要确定的产品决策

1. 首发形态优先做网页、平板应用还是桌面应用？这会影响手写体验、离线能力和文件导入方式。本稿以“桌面/平板优先，手机可读”为布局假设。
2. 资料处理优先本地完成还是允许上传到云端？这会影响隐私说明、同步、AI 费用和扫描件识别能力。
3. 第一批目标学生是中学、大学还是考研/考证人群？默认笔记栏目与模板需要随学科、年级调整。
4. 是否需要多设备同步与同学共享？当前按个人资料库设计，协作可在验证个人学习流程后另行设计。
5. 首版支持哪些模型服务商和接口形式？需要用真实账号验证连接、视觉能力与费用提示；不能假定所有接口都完全兼容。

以上决策不影响先做页面原型，但在确定开发方案与数据存储方式前应收敛。

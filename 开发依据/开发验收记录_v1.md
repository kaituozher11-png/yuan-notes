## 自动化与边界测试

- `npm test`：4 个测试用例通过。覆盖接口地址约束、来源摘录核对、模型成功/错误/鉴权、文档导入、图片上传与格式拒绝、无效页码、笔记保存/删除恢复、重排、已有 AI 笔记防覆盖、预览一次性提交、视觉图片发送、备份 ZIP、外站 Origin 拒绝。
- `npm run build`：构建通过。Vite 仍提示首页资源包超过 500 kB；PDF 阅读和导出已按需加载，后续可继续拆分编辑器依赖。
- `npm audit --omit=dev`：0 项已知漏洞。

## 未完成或尚未验证的项目

1. **真实模型服务商**：只有本机模拟的 OpenAI Chat Completions 接口完成端到端测试。没有用户密钥，因此不能宣称任一真实服务商、费用、限流或扫描件识别质量已通过。应用不会索取或记录用户密钥用于测试。
2. **复杂文档**：未覆盖大体积 100 MB 临界值、加密 PDF、复杂公式/表格、异常字体及旧式 PPT/DOC 的真实样本。Word 页码取转换后的 PDF 页，原文件重新排版后的链接迁移尚未实现。
3. **编辑增强**：手写套索、图片交互缩放、导图复杂排版、跨文档链接、版本历史、多设备同步和离线编辑尚未实现。当前撤销/重做只在本次打开笔记时有效。
4. **平台**：当前为本机网页应用，手机和平板经浏览器视口检查；未封装桌面安装包，也未在实体平板手写笔和多浏览器上验收。

测试资料已移到 `test-output/test-data-2026-11-13/`，正式 `data/` 已重新初始化为空资料库。清理时自动审核拦截了递归删除，因此采用可恢复的归档方式。

因此，这是一版可运行、核心学习流程经过验证的应用，不能称为产品设计中每项能力都已“完美实现”。后续验收应使用用户自己的真实资料、所选模型服务商和目标设备，按上述未验证项继续测试与修正。

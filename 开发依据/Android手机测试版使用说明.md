# 源笔记 Android 离线测试版

## 安装

将 `release/源笔记-Android-离线测试版.apk` 发送到 Android 8.0 或更新的手机并安装。包名和签名与上一测试版相同，可覆盖安装。打开后直接进入资料库，不用填写电脑地址，也不用连接同一个 Wi-Fi。

## 离线使用

- 可直接导入手机上的 PDF，在手机本地阅读原文、写笔记、插入图片与公式、手写、画思维导图、添加关联和批注，并可使用模板及回收站。资料与笔记保存在本机应用数据中，关闭网络和重启应用后仍可打开。
- 离线版目前直接导入 PDF，最大 100 MB。Word、PPT 的原版式转换依赖电脑软件；需要先在其他设备上另存为 PDF 再导入手机。
- 资料库中的“备份资料库”将资料和笔记打包到手机“下载”目录；“恢复备份”会替换手机内现有资料，操作前请先备份。Android 8/9 的导出保存在应用专用下载目录。
- 手机应用数据被清除或应用被卸载后，本地资料可能被删除。请定期导出备份 ZIP。

## 智能生成

联网后，在“模型连接”添加用户自己的 HTTPS 模型接口、模型名称和 API 密钥，然后测试连接并按页生成笔记。模型请求由手机直接发送给服务商，不经过电脑测试服务。模型调用可能产生服务商费用。

断网点击“生成笔记”时会显示“无法生成智能笔记，请联网”。已保存的智能笔记和个人笔记在断网时仍可阅读和编辑。模型连接信息保存在当前手机应用中，旧测试版的浏览器模型配置不会自动转移。

## 从上一测试版迁移资料

上一测试版只是电脑服务的客户端，资料没有保存在旧 APK 内。若要保留之前在旧版中写的资料，**请在安装新版前**打开旧版，在资料库点击“备份资料库”，将下载的 ZIP 保存到手机；安装新版后，在资料库点击“恢复备份”选择该 ZIP。此迁移只需做一次，之后离线使用不再依赖电脑服务。新版也可恢复之前从网页版下载的完整资料备份。

## 验证与限制

- 网页构建及 48 项现有自动测试通过；浏览器验证了本地 PDF 导入、笔记保存后刷新、旧版备份恢复、断网提示，以及模拟模型响应后的格式测试和智能笔记保存。
- Android APK 已构建并完成签名与内容检查，包内含离线网页资源和 PDF 图片解码资源，版本号已升至 `0.2.2-offline`。PDF 加载提示不会再改变阅读区域宽度。
- 这次改造尚未在真实 Android 手机上重新测试文件导入、备份保存和真实模型接口。请用新版 APK 在手机上确认；真实服务商可能有地区网络或账号限制。
